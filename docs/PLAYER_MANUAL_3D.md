# คู่มือผู้เล่น — LAST LIGHT: 3D Tower Defense (Windows)

เกมหลักที่กำลังพัฒนาต่อ (`projects\last-light-3d\`) คู่มือฉบับ 2D reference อยู่ที่ [PLAYER_MANUAL.md](./PLAYER_MANUAL.md)

## เป้าหมาย

คุณคือช่างคุมแนวรบ (ตามบทของ ริน) วางป้อมจากเศษ Salvage ก่อนฝูง Hollows เดินตามถนนเข้า Shelter 09 เอาตัวรอดครบ 8 คลื่นและจัดการ **Rift Warden** ให้ได้ หาก Shelter Integrity หมดคือแพ้ (แพ้ก็ยังได้ Salvage ตามส่วนที่ทำได้)

## การควบคุม

| การกระทำ | Windows |
|---|---|
| เลือกชนิดป้อม | ปุ่ม 1–4 หรือปุ่มบน HUD |
| วางป้อม | คลิกซ้ายที่พื้นสนาม (จุดไฮไลต์ 12 จุดช่วยชี้ที่ดี) |
| อัปเกรดป้อม | คลิกซ้ายที่ป้อมที่วางไว้ (สูงสุด 2 ครั้ง) |
| ขายป้อม | คลิกขวาที่ป้อม (คืน 70% ของ Parts ที่ลงไป) |
| เริ่มคลื่น | Space หรือปุ่ม Start Wave |
| หยุดชั่วคราว / เล่นต่อ | Esc |
| กลับหน้า Title / เริ่มภารกิจใหม่ | ปุ่มบนเมนูหยุดชั่วคราวและหน้าผลรอบ |

ที่หน้า Title: เริ่มการรบ, "เล่นต่อจากภารกิจค้าง (คลื่น N)", วิธีการเล่น, เรื่องราว, ตั้งค่า, ออกจากเกม

## ป้อม 4 แบบ

| ป้อม (ปุ่ม) | ราคา | บทบาท |
|---|---|---|
| Field Turret (1) | 80 Parts | ยิงเดี่ยวรวดเร็ว — DPS ต่อเนื่อง |
| Sonic Resonator (2) | 120 Parts | กระสุนระเบิดวงกว้าง — เจาะฝูง |
| Tangle Emitter (3) | 60 Parts | ช้าศัตรู 30% ในรัศมี — ยืดเวลาในระยะยิงป้อมอื่น |
| Arc Cannon (4) | 140 Parts | ลูกใหญ่ระเบิดแรง ระยะไกล — สำหรับเป้าหนา |

ทุกป้อมอัปเกรดได้ 2 ระดับ (ราคาต่อระดับแสดงในเกม) และขายคืนได้ 70% เสมอ — ผิดพลาดไม่ใช่ game over

## กติกาสำคัญ

- เริ่มภารกิจด้วย **120 Parts**; Shelter มี **10 Integrity** (+2 ต่อ Barricade level ใน profile แต่ปุ่มซื้อระดับ meta ยังไม่เปิดใน build นี้)
- กำจัดศัตรูได้ Parts; ศัตรูที่ลอดผ่านถึง Shelter ลด Integrity **1** (Rift Warden **3**) และไม่ให้รางวัล
- จบคลื่นได้โบนัส **20 + 5 × Integrity ที่เหลือ**; กด Space ทีหลังตั้งแนวได้จนกว่าจะเริ่มคลื่น (ดูตัวอย่างศัตรูล่วงหน้า)
- ระบบกำหนดเป้าแบบ "first" — ป้อมยิงศัตรูที่เดินนำหน้าสุดในระยะ

## ผลรอบ และ "เล่นต่อจากภารกิจค้าง"

- ชนะ: ได้ **150 + 5 × Integrity ที่เหลือ** Salvage
- แพ้: ได้ **10 × จำนวนคลื่นที่ผ่าน + 2 × Integrity ที่เหลือ** Salvage
- Salvage สะสมใน profile (`user://profile.json`) ใช้กับ level ที่วางแผนไว้ในเฟสถัดไป
- ปิดเกมกลางรอบที่มีความคืบหน้า ระบบจะบันทึก snapshot อัตโนมัติ (`user://session_snapshot.json`) — เปิดเกมใหม่จะมีปุ่ม "เล่นต่อจากภารกิจค้าง" ให้กลับมาที่ต้นคลื่นที่ค้างพร้อมป้อม/Parts/Integrity เดิม

## การตั้งค่า

แผง "ตั้งค่า" (จาก Title และจากเมนูหยุดชั่วคราว) มี: ระดับเสียง Master / SFX / Music (สไลเดอร์), **ลดแสงวาบหน้าจอ (Reduce flashes)** และ **ลดการเคลื่อนไหว (Reduce motion)** สำหรับ VFX สั่นไหว — ตั้งค่าและ profile บันทึกลง `user://` เปิดครั้งถัดไปจำค่าเดิม
