# คู่มือผู้เล่น — LAST LIGHT: 3D Tower Defense (Windows)

เกมหลักที่กำลังพัฒนาต่อ (`projects\last-light-3d\`) คู่มือฉบับ 2D reference อยู่ที่ [PLAYER_MANUAL.md](./PLAYER_MANUAL.md)

## เป้าหมาย

คุณคือช่างคุมแนวรบ (ตามบทของ ริน) วางป้อมจากเศษ Salvage ก่อนฝูง Hollows เดินตามถนนเข้า Shelter 09 เอาตัวรอดครบ 8 คลื่นและจัดการ **Rift Warden** ให้ได้ หาก Shelter Integrity หมดคือแพ้ (แพ้ก็ยังได้ Salvage ตามส่วนที่ทำได้)

## การควบคุม

| การกระทำ | Windows |
|---|---|
| เลือกชนิดป้อม | ปุ่ม 1–4 หรือปุ่มบน HUD |
| วางป้อม | คลิกซ้ายที่พื้นสนาม (จุดไฮไลต์ 12 จุดช่วยชี้ที่ดี) |
| อัปเกรดป้อม | คลิกซ้ายที่ป้อมที่วางไว้ (สูงสุด 2 ครั้ง) |
| ขายป้อม | คลิกขวาที่ป้อม (คืน 70% ของ Parts ที่ลงไป) |
| เปลี่ยนโหมดเลือกเป้าของป้อม | ชี้เมาส์ที่ป้อมแล้วกด **T** (วน: หัวแถว → ท้ายแถว → แข็งสุด → อ่อนสุด) |
| เดินริน | ปุ่ม **WASD** |
| รินยิงที่จุด | คลิกซ้ายที่พื้นสนาม |
| รินยิงด้านหน้า | ปุ่ม **F** |
| เรียกกลับ / เรียกรินลงสนาม | ปุ่ม **H** |
| เริ่มคลื่น | Space หรือปุ่ม Start Wave |
| หยุดชั่วคราว / เล่นต่อ | Esc |
| กลับหน้า Title / เริ่มภารกิจใหม่ | ปุ่มบนเมนูหยุดชั่วคราวและหน้าผลรอบ |

ที่หน้า Title: เริ่มการรบ, "เล่นต่อจากภารกิจค้าง (คลื่น N)", วิธีการเล่น, เรื่องราว, ตั้งค่า, ออกจากเกม — พร้อมแผง **"ฐานที่มั่น"** มุมล่างซ้าย: สถิติของคุณ (Salvage / ชนะ / คลื่นไกลสุด), ระดับ Barricade ปัจจุบัน และปุ่มซื้ออัปเกรด (เงินไม่พอจะบอกบนหน้าจอว่าขาดอีกเท่าไร)

## ป้อม 4 แบบ

| ป้อม (ปุ่ม) | ราคา | บทบาท |
|---|---|---|
| Field Turret (1) | 80 Parts | ยิงเดี่ยวรวดเร็ว — DPS ต่อเนื่อง |
| Sonic Resonator (2) | 120 Parts | กระสุนระเบิดวงกว้าง — เจาะฝูง |
| Tangle Emitter (3) | 60 Parts | ช้าศัตรู 30% ในรัศมี — ยืดเวลาในระยะยิงป้อมอื่น |
| Arc Cannon (4) | 140 Parts | ลูกใหญ่ระเบิดแรง ระยะไกล — สำหรับเป้าหนา |

ทุกป้อมอัปเกรดได้ 2 ระดับ (ราคาต่อระดับแสดงในเกม) และขายคืนได้ 70% เสมอ — ผิดพลาดไม่ใช่ game over

## กติกาสำคัญ

- เริ่มภารกิจด้วย **120 Parts**; Shelter เปิดคืนด้วย Integrity = **10 + 2 × ระดับ Barricade** (profile เริ่ม Lv1 → **12**; ซื้อเพิ่มได้ถึง Lv2 → 14 ที่แผงบนหน้าเมนู)
- กำจัดศัตรูได้ Parts; ศัตรูที่ลอดผ่านถึง Shelter ลด Integrity **1** (Rift Warden **3**) และไม่ให้รางวัล
- จบคลื่นได้โบนัส **20 + 5 × Integrity ที่เหลือ**; กด Space ทีหลังตั้งแนวได้จนกว่าจะเริ่มคลื่น (ดูตัวอย่างศัตรูล่วงหน้า)
- **โหมดเลือกเป้า (T ต่อป้อม):** หัวแถว (ค่าเริ่มต้น — ยิงตัวนำหน้าสุด), ท้ายแถว (ตัวพึ่งเข้าระยะ), แข็งสุด (HP สูงสุด), อ่อนสุด (HP ต่ำสุด) — ป้ายเหนือป้อมบอกโหมดที่เปิดอยู่ ซ่อนเมื่ออยู่โหมดค่าเริ่มต้น

## ริน — นักลงสนามของคุณ

รินอยู่บนสนามตั้งแต่เริ่มต้นทุกคืน (auto-deploy) เดินหาแนวชั้นดีด้วย **WASD** ยิงด้วย **คลิกซ้าย** (ที่จุด) หรือ **F** (ด้านหน้าตัว) ควบคู่กับป้อมได้อิสระ — ถ้าอยากโคตร "วางป้อมล้วน" ให้กด **H** เรียกกลับและกดอีกครั้งเมื่ออยากได้เธอคืนสนาม

## ภารกิจและการเดินหน้า

- ภารกิจแรกใช้แผนที่ "เส้นทางสู่เชลเตอร์ 09" — ชนะครบ 8 คลื่น → ปลดล็อก **map 2 "ที่ราบริฟท์"** (กดปุ่ม "ด่านต่อไป ▶" บนหน้าผลรอบ): พื้นใหญ่ขึ้น ถนนยาวขึ้นโค้งมากขึ้น คลื่นตึงขึ้นตามสมควร
- ภารกิจค้างบันทึกอัตโนมัติรู้จักแผนที่ที่ค้าง — resume กลับเข้าแผนที่เดิมได้ถูกต้อง

## ผลรอบ และ "เล่นต่อจากภารกิจค้าง"

- ชนะ: ได้ **150 + 5 × Integrity ที่เหลือ** Salvage
- แพ้: ได้ **10 × จำนวนคลื่นที่ผ่าน + 2 × Integrity ที่เหลือ** Salvage
- Salvage สะสมใน profile (`user://profile.json`) ใช้กับ level ที่วางแผนไว้ในเฟสถัดไป
- ปิดเกมกลางรอบที่มีความคืบหน้า ระบบจะบันทึก snapshot อัตโนมัติ (`user://session_snapshot.json`) — เปิดเกมใหม่จะมีปุ่ม "เล่นต่อจากภารกิจค้าง" ให้กลับมาที่ต้นคลื่นที่ค้างพร้อมป้อม/Parts/Integrity เดิม

## การตั้งค่า

แผง "ตั้งค่า" (จาก Title และจากเมนูหยุดชั่วคราว) มี: ระดับเสียง Master / SFX / Music (สไลเดอร์), **ลดแสงวาบหน้าจอ (Reduce flashes)**, **ลดการเคลื่อนไหว (Reduce motion)** สำหรับ VFX สั่นไหว และ **ภาษา (Language): ไทย / English** — การเปลี่ยนภาษามีผลทันทีทุกหน้าที่เปิดอยู่ (เมนูหลัก, HUD, แผงตั้งค่า) — ตั้งค่าและ profile บันทึกลง `user://` เปิดครั้งถัดไปจำค่าเดิม (ค่าเริ่มต้นภาษาไทย)
