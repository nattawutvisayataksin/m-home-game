# MANUAL — Kick Hero Arena

> คู่มือการเล่น + วิธีเทสต์ (เชิงเทคนิคด้านล่าง)

## 1. การเล่น

### คีย์ผู้เล่น 1 (P1 — น้ำเงิน, ฝั่งซ้าย)

| ปุ่ม | ทำอะไร |
|---|---|
| **W A S D** | วิ่ง 8 ทิศ — ทิศที่กดล่าสุดคือทิศ "เล็ง" |
| **C** | เตะ/ยิง — บอลของเรา: ยิงตามทิศเล็ง (แรง 260) / บอลลอย: ยิง / **บอลใคร: แย่ง!** |
| **V** | สกิลพิเศษ — เตะแรงสุด (430) cooldown 2.5s (เช่น จ่ายไกลหรือแย่งเร็ว) |
| **Space** | **Sprint** — เร่งเร็ว ×1.75 ใช้สไตมิน่า (แถบบนจอ) ใช้เข้าแย่งบอล / เลี้ยงหลบ |
| X | ไอเทม (ยังไม่เปิด — เตรียมอนาคต) |

### คีย์ผู้เล่น 2 (P2 — แดง, ฝั่งขวา)

| ปุ่ม | ทำอะไร |
|---|---|
| **ลูกศร** | วิ่ง 8 ทิศ |
| **K** | เตะ/ยิง/แย่ง |
| **L** | สกิลพิเศษ |
| **Shift** | Sprint |
| J | ไอเทม (ยังไม่เปิด) |

### ระบบครองบอล (possession)

- บอล "ติดตัว" เดินชนบอลว่างได้เลย โดยไม่ต้องเตะ
- **ความจริง 1:** บอลติดตัวจนกว่าจะโดน "เตะ C/K หรือสกิล V/L ของฝ่ายใดฝ่ายหนึ่ง"
- จับคู่ info: ใครเตะโดนบอลของเจ้าของ → เจ้าของเดิม "สะดุด" (stun 0.45 วิ — วิ่งช้า ช่วงแรกง่อน) บอลหลุดนุ่ม ๆ
- หลังปล่อยบอล (เตะออก) มี "ล็อกเพิ่มห่าง" 0.35 วิใครวิ่งชนทันทีจะไม่ครองแบบตีบอลหลง

### กติกาแมตช์

- 90 วินาที / ชนะ 3 ประตู
- ประตูซ้าย/ขวาอยู่ครึ่งกลางกำแพง — GK โกโก้เฝ้าช่องทั้งสองฝั่ง
- ประตูได้แล้ว: บอลกลางสนาม นับ 3+2+1 เริ่มใหม่
- **Esc / M** = กลับเมนู, **R** ตอนจบเกม = เริ่มแมตช์ใหม่

## 3. วิธีเทสต์ (สำหรับ agent / dev)

### คำสั่งรัน headless (พิมพ์ log `[ARENA] ...`)

```powershell
$gd = "C:\Users\admin\AppData\Local\Microsoft\WinGet\Packages\GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe\Godot_v4.7.2-stable_win64_console.exe"
$proj = "C:\Users\admin\Desktop\m-home-game\projects\my-game"  # ← สันนีษะนั่งที่อยู่โปรเจกต์ ที่ใหม่เปลี่ยนเป็น clone ใหม่

# ตรวจ parser / scene ความสะอาด
& $gd --headless --path $proj --import ; & $gd --headless --path $proj --quit

# แมตช์เต็ม AI (≈95 วินาทีจริง) — ดูได้ GOAL / MATCH END จาก stdout
& $gd --headless --path $proj "res://scenes/arena.tscn" --quit-after 6000 -- hard

# Training สั้น ๆ ยืนยันระบบรันได้
& $gd --headless --path $proj "res://scenes/arena.tscn" --quit-after 1200 -- training
```

### เกณฑ์ผ่านของเทสต์ AI

ผ่านเมื่อ stdout บรรทัดครบ (โหมด AI):
1. `[ARENA] ARENA READY — mode=X`
2. `[ARENA] KICKOFF → PLAY (บอลกลางสนาม)`   (หลัง countdown 2 วิ)
3. `[ARENA] GOAL → ...` อย่างน้อย 1 ประตู — ยืนยัน AI เตะจริง
4. `[ARENA] MATCH END :: ...` — ยืนยัน FSM จบถูกต้อง
5. **ไม่มี** บรรทัด `SCRIPT ERROR` ใด ๆ

### เกณฑ์ผ่านของเทสต์ Training

ได้ข้อ 1, 2, 5 จากด้านบน (ไม่จบแมตช์เป็น training ไม่จับเวลา — บอลได้เข้าประตูจะเห็น `GOAL → ได้ๆ! ต่อไป` ถ้าโหมดว่างนานพอ)

> ⚠ **ห้ามรัน headless แบบไม่ใส่ `--quit-after`** — แมตช์ไม่จบเอง ข้างในเกมจะวน node ตลอด
