# คู่มือผู้เล่น — LAST LIGHT (ฉบับร่าง)

## เป้าหมาย

ปกป้อง Beacon 09 จากศัตรูที่เคลื่อนลงมาจากด้านบน กำจัดศัตรูให้ได้มากที่สุดก่อนมันข้ามแนวด้านล่าง และเอาชนะบอสเมื่อจบภารกิจ

## การควบคุม (แบบร่าง)

| การกระทำ | Windows | Android |
|---|---|---|
| ขยับซ้าย/ขวา | A/D หรือ ←/→ | ลากหรือใช้ virtual stick ที่ด้านล่าง |
| ยิง | ยิงอัตโนมัติ | ยิงอัตโนมัติ |
| Pulse | Space เมื่อ Resonance เต็ม | แตะ Pulse เมื่อเกจเต็ม |
| Overclock | E เมื่อ Resonance เต็ม | แตะ Overclock เมื่อเกจเต็ม |
| Pause | Esc | ปุ่ม pause |

เกมจริงต้องแสดง prompt ตามอุปกรณ์ที่ใช้ และให้ปรับปุ่ม/ลด screen shake/flash ได้เมื่อ settings พร้อม

## Resonance: เลือกใช้พลัง

การกำจัดศัตรูเติมเกจ เมื่อเต็มเลือกได้หนึ่งทาง:

- **Overclock:** เพิ่มพลังอาวุธของรอบนี้ ช่วยกำจัดคลื่นถัดไป
- **Pulse:** ใช้พลังทันทีเพื่อผลักหรือหยุดศัตรูที่กำลังใกล้แนวป้องกัน

อย่าปล่อยศัตรูที่ส่งสัญญาณพุ่งลงเข้าถึง Beacon; หากไม่แน่ใจ ให้ใช้ Pulse ก่อนที่ Integrity จะหมด

## แพ้และชนะ

- ศัตรูที่ข้ามเส้น Beacon ทำให้ Integrity ลด
- Integrity หมด = ภารกิจล้มเหลว; ผลสรุปจะแสดงสาเหตุและ Salvage ที่ได้
- เอาชนะบอสท้ายภารกิจและรักษา Beacon ให้ทำงาน = ภารกิจสำเร็จ
- ความคืบหน้าสะสมบางส่วนแม้แพ้; รายละเอียด reward จะปรับหลัง playtest

> เกมยังอยู่ในช่วง scaffold; ตารางควบคุม/ค่ากติกาข้างต้นเป็น design draft ยังไม่มี gameplay ให้ทดลอง
