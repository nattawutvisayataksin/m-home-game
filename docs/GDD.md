# Game Design Document — LAST LIGHT: สัญญาณสุดท้าย

**สถานะ:** Playable alpha — design baseline ที่ยืนยันด้วย automated tests; balance ยังรอ playtest
**ประเภท:** 2D portrait survival-defense shooter
**Engine:** Godot 4.7.2
**ผู้เล่น:** 1 คน, PvE
**เป้าหมายปัจจุบัน:** Windows PC; Android ถูกพักไว้จนกว่า core loop จะสนุกและผ่าน playtest
**Session เป้าหมาย:** สูงสุด 5 นาทีต่อรอบ

## 1. High concept

ผู้เล่นคือผู้รอดชีวิตที่ยืนคุมแนวหน้าของ Shelter ฝูง Hollows บุกจากถนนที่พังทลาย ผู้เล่นขยับซ้าย–ขวาและยิงอัตโนมัติเพื่อหยุดศัตรูก่อนถึงที่พักพิง เก็บชิ้นส่วนจากศัตรูเพื่อเสริมอาวุธระหว่างคลื่น และนำ Salvage ที่เหลือไปเสริมแนวป้องกันก่อนเริ่มรอบใหม่:

- **Weapon Upgrade:** ใช้ชิ้นส่วนเพิ่ม damage และ fire rate ได้หลายระดับในรอบเดียว
- **Emergency Blast:** ใช้ชิ้นส่วนปล่อยระเบิดฉุกเฉิน กำจัดศัตรูที่เข้าใกล้แนวพักพิง
- **Barricade Upgrade:** ใช้ Salvage ระหว่างรอบเพิ่ม Integrity เริ่มต้นของ Shelter

การตัดสินใจคือจะใช้ชิ้นส่วนกับกำลังยิงต่อเนื่อง หรือเก็บไว้กันไม่ให้แนวป้องกันแตก

## 2. Pillars

1. **ป้องกันพื้นที่ที่มีความหมาย:** ผู้เล่นยืนอยู่หน้า Shelter; ทุกศัตรูที่หลุดผ่านแนวป้องกันทำให้ที่พักพิงเสียหาย
2. **เล่นง่าย แต่ตัดสินใจมีน้ำหนัก:** ยิงอัตโนมัติและควบคุมการย้ายตำแหน่งกับการใช้ชิ้นส่วน
3. **รอบสั้นและพลาดแล้วอยากเริ่มใหม่:** ทุกการเล่นให้ผลตอบรับชัด ไม่บังคับฟาร์มนาน
4. **ความก้าวหน้ามองเห็นได้:** ผู้เล่นและฐานแข็งแกร่งขึ้นจากการเลือกอัปเกรด ไม่ใช่จากการฟาร์มยาว

## 3. Core loop

1. เริ่มป้องกัน Shelter จากคลื่น Hollows
2. เคลื่อนซ้าย–ขวาเพื่อจัดแนว; ปืนยิงขึ้นอัตโนมัติและกระสุนหยุดที่เป้าหมายแรก
3. กำจัดศัตรูเพื่อเก็บ **Parts**; ทุก 100 Parts เลือกอัปเกรดปืน หรือใช้ Emergency Blast
4. ป้องกันแนวให้นานพอ จัดการ Rift Warden ที่ท้ายรอบ
5. รับ Salvage ตามผลงานและซื้อ Barricade Upgrade เพื่อเริ่มรอบถัดไปด้วย Integrity เพิ่มขึ้น

## 4. กติกา MVP

- พื้นที่เล่นคงสัดส่วน **9:16**; ฉากเป็นถนน/แนวป้องกันบนพื้น ไม่ใช่ฉากอวกาศหรือยาน
- ผู้เล่นเป็นมนุษย์เดินเท้า เคลื่อนที่ตามแกน X ในแถบล่าง; ขอบซ้าย/ขวาจำกัดการเคลื่อนที่
- ปืนยิงขึ้นอัตโนมัติ; การย้ายตำแหน่งให้ผู้เล่นจัดแนวยิงและหลบ Telegraph
- ศัตรูที่ข้ามแนวทำความเสียหายให้ **Shelter Integrity** แล้วออกจากฉาก; เกมจบเมื่อ Integrity หมด
- ศัตรูที่ถูกกำจัดให้ Parts; ทุก 100 Parts ใช้อัปเกรดปืนได้สูงสุดเลเวล 6 หรือใช้ Emergency Blast
- Barricade Upgrade ซื้อระหว่างรอบได้สูงสุด 2 ระดับ เพิ่ม Integrity เริ่มต้นครั้งละ 1
- ภารกิจ prototype ยาวสูงสุด 5 นาที; Rift Warden เข้าสนามที่นาที 4 และภารกิจจบเมื่อชนะหรือ Shelter พัง
- จบรอบแล้วได้รับ Salvage ตามผลงานแม้แพ้; ใช้เสริมแนว Barricade และปลดล็อก lore archive

**ค่าตัวเลขทั้งหมดเป็นค่าเริ่มต้นสำหรับ playtest** ไม่ใช่ balance ที่พิสูจน์แล้ว

## 5. ศัตรูและแรงกดดัน

| บทบาท | การเคลื่อนที่/สัญญาณ | บทบาทต่อการตัดสินใจ |
|---|---|---|
| Drifter | เดินเข้าหาแนวตรง ๆ, silhouette ใหญ่ | เป้าหมายฝึกจัดแนวและวัด DPS |
| Skitter | ส่ายซ้าย–ขวา | บังคับให้ผู้เล่นปรับตำแหน่ง |
| Dasher | หยุดส่งสัญญาณสั้น ๆ ก่อนพุ่งเข้าแนว | ลงโทษการยืนตำแหน่งเดิม |
| Rift Warden (บอส) | กล้ามเนื้อกลายพันธุ์; เตือนเลนก่อนพุ่งชนแนว | ทดสอบการอ่าน Telegraph และบริหาร Parts |

ไม่ใช้ pathfinding ใน MVP: ศัตรูเคลื่อนใน lane/trajectory ที่กำหนดไว้ ความต่างมาจากจังหวะ, ความเร็ว, การส่าย และ telegraph. Bulwark และ multi-phase boss ยังไม่อยู่ใน playable build

## 6. โครงรอบและความยาก

- 0:00–1:00 — Drifter และการจัดแนว; Parts เริ่มสะสม
- 1:00–2:00 — เพิ่ม Skitter และ lane pressure
- 2:00–4:00 — เพิ่ม Dasher; ปรับ spawn interval ตาม wave data
- 4:00–5:00 — Rift Warden; ผู้เล่นต้องหลบแนวโจมตีที่ telegraph

Mission/Wave definitions อยู่ใน `.tres`; lane jitter ใช้ RNG ที่จำกัดในขอบเขต

## 7. Progression

### ระหว่างรอบ

- Parts แลก Weapon Upgrade หรือ Emergency Blast ตามสถานการณ์
- อาวุธเริ่มต้นเป็นปืนไรเฟิล; อัปเกรด damage/fire rate ได้สูงสุดเลเวล 6 ในรอบ
- ระหว่างรอบใช้ Salvage ซื้อ Barricade Upgrade สูงสุด 2 ระดับ; ยังไม่มีระบบสร้าง/วางสิ่งปลูกสร้างอิสระ

### ระหว่างภารกิจ

- ได้ Salvage = `max(kills + (ชนะ ? 5 : 0) - breaches, 0)`
- ใช้ Salvage ซื้อ Barricade Upgrade ระดับ 1/2 ในหน้า Title; เพิ่ม Integrity เริ่มต้นของรอบถัดไป 1 ต่อระดับ
- ยอดสะสม 20/75/150 ปลด lore archive; profile ใช้ schema-versioned save
- ไม่มี hunger/thirst, crafting หรือ inventory ขนาดใหญ่ใน MVP; Barricade เป็น meta-upgrade เดียวเพื่อให้ loop กระชับ

## 8. UX, input และ accessibility

- **Windows:** A/D หรือปุ่มลูกศร = เคลื่อนที่, Space = Emergency Blast, E = Weapon Upgrade, Esc = pause; ปืนยิงอัตโนมัติ
- **Android:** ยังไม่อยู่ใน scope ของ fun-first iteration
- Gameplay ใช้ action names ใน InputMap; gamepad mapping/rebinding ยังไม่อยู่ใน build นี้
- UI ยึด anchor/container และคง field 9:16
- สีไม่ใช่สัญญาณเดียว: เพิ่มรูปทรง ไอคอน และ animation telegraph
- ตัวเลือก: Master volume, ลด flash, ข้อความขนาดใหญ่ และภาษาไทย/อังกฤษ; แยก audio buses ไว้ให้ขยายต่อ

## 9. เสียงและ game feel

- Audio buses: Master, Music, SFX, UI, Ambience, Voice; playable build มี ambient loop สังเคราะห์ต้นฉบับและ SFX สังเคราะห์
- ยิงปกติใช้เสียง/impact สั้น; เก็บ Parts, Weapon Upgrade และ Emergency Blast มีเสียงแยกกัน
- feedback ต้องไม่บัง telegraph หรือทำให้เกิดอาการเวียนหัว; build นี้ยังไม่มี camera shake และไม่ย้าย collider เพื่อทำ feedback

## 10. เป้าหมายการทดสอบเบื้องต้น

ใช้เป็นสมมติฐานสำหรับ playtest ไม่ใช่คำรับรอง:

- ผู้เล่นใหม่เข้าใจการขยับ/ยิงได้ภายใน 15 วินาที โดยไม่ต้องอ่านบทสนทนา
- ผู้เล่นเข้าใจ Parts และเลือกอัปเกรดปืนหรือใช้ Emergency Blast ได้เอง
- ศัตรูตัวที่เร็วมีช่วงเตือนที่ผู้เล่นตอบสนองได้; ความเสียหายจาก breach ระบุได้ว่าเกิดจากอะไร
- รอบแรกของผู้เล่นใหม่ไม่ลงโทษจนหมดโอกาสเห็นระบบเลือกใช้เกจ
- ทดสอบภาระฉากเป้าหมาย 60 FPS บน Windows ก่อน lock ตัวเลขจำนวนศัตรู/กระสุน
- ตรวจ UI บน 9:16, 16:9 (แถบข้าง) และจอความละเอียดต่ำ

## 11. Non-goals และ scope guard

- ไม่ทำ 3D gameplay, multiplayer, online backend, open world, freeform base construction หรือระบบ crafting ใน MVP
- ไม่สร้าง procedural level ก่อนที่ wave ที่ออกแบบมือจะสนุก
- ไม่ทำการซื้อขายเงินจริงหรือระบบสุ่มของแบบกาชา
- ไม่ทำ content จำนวนมากก่อนผ่าน vertical-slice gate ใน [ROADMAP.md](./ROADMAP.md)

## 12. คำถามค้างสำหรับ playtest

- การยืนป้องกันแนวและเลื่อนซ้าย/ขวาทำให้รู้สึกว่าคุมสถานการณ์ได้หรือไม่?
- การอัปเกรดปืนซ้ำทุก 100 Parts รู้สึกมีความหมายพอหรือควรมีตัวเลือกอัปเกรด?
- ระยะเวลา 5 นาที, อัตราเกจเต็ม และความยากของ Warden เหมาะกับ session สั้นหรือไม่?
