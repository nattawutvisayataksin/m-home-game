# LAST LIGHT — Playtest Plan

## Current focus

This iteration is for the Windows keyboard survival-defense loop. Android implementation and
device validation are deferred; do not treat them as playtest prerequisites.

## Before starting

1. Use a fresh profile if you want to test first-run unlocks; keep your normal `user://profile.json` backed up.
2. Record Windows resolution/window size, keyboard, language, large-text/reduce-flash settings, and build version.
3. Do not record names or other personal data. A short written note is enough.

## First-run usability

- Start the mission without reading this document. Note whether the on-foot survivor and Shelter-defense objective are immediately clear.
- Observe whether Parts, repeated weapon upgrades, and Emergency Blast are understandable.
- Use several weapon upgrades and note whether each one feels distinct and useful.
- At Title, buy a Barricade upgrade and verify the next run starts with more Shelter Integrity.
- Record any label, control, or warning that was unclear.

## Combat and boss

- Let at least one enemy breach; verify Shelter Integrity loss is visible and attributable.
- Observe Skitter movement and the Dasher warning before its fast descent.
- At 4:00, watch for the Warden warning. Move away from the marked lane before its attack; record whether the warning gave enough time.
- Finish by defeating the Warden or losing the Shelter. Verify the result screen, Salvage earned, and return/restart controls.

## Persistence and accessibility

- After a result, return to Title and confirm Salvage/records are updated and can buy a Barricade upgrade.
- Earn at least 20 Salvage and check that the first Field Archive entry unlocks.
- Change language, master volume, large text, and Reduce Flashes; quit and reopen to verify settings persist.
- Test pause/resume and restart using keyboard focus navigation.
- Check the Windows windowed layout at the default portrait size and a wider desktop aspect ratio.
