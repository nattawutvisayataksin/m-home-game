# Story Bible — LAST LIGHT: สัญญาณสุดท้าย

## Logline

เมื่อรอยแยกเหนือเมืองปล่อยฝูงสิ่งมีชีวิตที่ไหลลงมากับพายุแม่เหล็ก **ริน** ช่างซ่อมสัญญาณคนสุดท้ายต้องยืนคุมแนวปืนของ Beacon 09 ให้ได้นานพอที่จะส่งสัญญาณอพยพครั้งสุดท้าย—โดยใช้พลังจากศัตรูที่ล้มลงว่าจะเสริมปืนเพื่ออนาคต หรือหยุดฝูงที่กำลังจะทะลวงแนวในตอนนี้

## โลก

โลกชายฝั่งหลังเหตุการณ์ **คืนไร้ดาว**: แสงจากรอยแยกทำให้ระบบสื่อสารและโครงข่ายพลังงานล่ม สิ่งมีชีวิตรูปร่างคล้ายเศษกระจกที่เรียกว่า **Hollows** ปรากฏบนท้องฟ้าและดิ่งลงสู่พื้นดินตามสัญญาณพลังงาน

Beacon 09 คือเสาส่งสัญญาณอพยพแห่งสุดท้ายที่ยังทำงานอยู่ การป้องกันไม่ได้หมายถึงการกอบกู้โลกในทันที แต่ซื้อเวลาให้ผู้รอดชีวิตได้รับพิกัดปลอดภัยและเปิดเส้นทางอพยพได้

## ตัวละคร

- **ริน (Rin):** ช่างซ่อมระบบที่ไม่ใช่ทหาร; เก่งแก้ปัญหาเฉพาะหน้า แต่แบกความรู้สึกผิดที่ออกจากเขตอพยพช้าเกินไป เป็นตัวละครที่ผู้เล่นตั้งชื่อ/ปรับรูปลักษณ์ได้ในอนาคต
- **มีรา (Mira):** ผู้ส่งสัญญาณจากศูนย์อพยพ เสียงวิทยุที่ชี้เป้าภัยและค่อย ๆ เปิดข้อมูลของ Beacon; ไม่อ่านบทยาวระหว่างคลื่นหนัก
- **Hollows:** ฝูงสิ่งมีชีวิตจากรอยแยก ไม่มีบทพูด ใช้พฤติกรรมและรูปลักษณ์บอกชนิด/ภัย
- **Rift Warden:** Hollow ขนาดใหญ่ที่ขวางสัญญาณสุดท้ายและทดสอบการตัดสินใจของผู้เล่น

## โครงเรื่องหนึ่งภารกิจ (MVP)

1. **สัญญาณขาดหาย:** รินมาถึง Beacon 09; มีราขอให้ซ่อมเสาโดยคุมแนวป้องกัน
2. **คลื่นแรก:** Drifter และ Skitter สอนการจัดแนวและระบบ Resonance ผ่านภาพ/UI ไม่ใช้ tutorial wall-of-text
3. **ทางเลือก:** แหล่งพลังงานเต็ม; มีราเตือนว่ามีฝูงกำลังลงมา ผู้เล่นเลือก Overclock หรือ Pulse ด้วยตนเอง
4. **เสียงเรียกจากหอส่งสัญญาณ:** บันทึกวิทยุเผยว่ามีผู้รอดชีวิตที่หายไปยังส่งสัญญาณจากพื้นที่เหนือแนว
5. **Rift Warden:** บอสขัดขวางการส่งสัญญาณ ผู้เล่นใช้สิ่งที่อัปเกรดหรือเกจที่เก็บไว้เพื่อเอาตัวรอด
6. **Beacon ออนไลน์:** ส่งพิกัดอพยพสำเร็จ; จบด้วยสัญญาณตอบรับที่บอกว่าการเดินทางต่อยังมีความเสี่ยง

## การเล่าเรื่องในเกม

- ใช้ radio barks สั้น ๆ ก่อน/หลัง wave และเฉพาะเหตุการณ์สำคัญ
- ใช้ข้อความสรุปหลังภารกิจสำหรับข้อมูลที่ไม่ควรขัดจังหวะ action
- บันทึกเสียง/ข้อความ optional ให้ผู้เล่นเลือกอ่าน
- UI เตือนภัยด้วยไอคอน/ภาพ/เสียงที่ไม่บังบริเวณล่างของสนาม
- แยกข้อความด้วย localization key ตั้งแต่เริ่ม; ไม่ฝังประโยคสำคัญไว้ใน logic

## น้ำเสียงและธีม

- **น้ำเสียง:** มีความหวังแบบระมัดระวัง; คนธรรมดาช่วยกันด้วยการทำงานเล็ก ๆ ที่สำคัญ
- **ธีม:** การเตรียมอนาคตกับการช่วยชีวิตตรงหน้าเป็นคุณค่าที่แข่งขันกัน แต่ไม่มีทางเลือกใดถูกหรือผิดแบบตายตัว
- **หลีกเลี่ยง:** ความสิ้นหวังต่อเนื่อง, บทพูดยาวทับการเล่น, การลงโทษทางเนื้อเรื่องจากการแพ้

## ขอบเขตเนื้อเรื่อง

MVP เล่าเหตุการณ์หนึ่งภารกิจและหนึ่งบอสให้จบในตัว ส่วนหลายเขต/หลายตอนเป็นส่วนขยายหลังพิสูจน์ core loop แล้ว ไม่ต้องสร้างจักรวาลขนาดใหญ่หรือ cinematic ก่อน prototype
