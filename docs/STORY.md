# Story Bible — LAST LIGHT: สัญญาณสุดท้าย

## Logline

หลังคืนไร้ดาว **ริน** ช่างซ่อมผู้รอดชีวิตยืนคุมแนวหน้าของ Shelter 09 ด้วยปืนไรเฟิลที่ซ่อมจากเศษอะไหล่ เขาต้องหยุดฝูง Hollows ไม่ให้ทะลวงแนว ขณะเก็บ Salvage ไปเสริม Barricade และทำให้อาวุธพร้อมรับคลื่นถัดไป

## โลก

โลกชายฝั่งหลังเหตุการณ์ **คืนไร้ดาว**: แสงจากรอยแยกทำให้ระบบสื่อสารและโครงข่ายพลังงานล่ม สิ่งมีชีวิตกลายพันธุ์ที่เรียกว่า **Hollows** ปรากฏตามถนนและเขตอพยพ พวกมันถูกดึงดูดด้วยเสียงและความร้อนจากกลุ่มผู้รอดชีวิต

Shelter 09 คือที่พักพิงชั่วคราวที่มีเสาส่งสัญญาณอพยพทำงานอยู่ การป้องกันไม่ได้หมายถึงการกอบกู้โลกในทันที แต่ซื้อเวลาให้ผู้รอดชีวิตซ่อมแนว Barricade รับเสบียง และเปิดเส้นทางอพยพ

## ตัวละคร

- **ริน (Rin):** ช่างซ่อมระบบที่ไม่ใช่ทหาร; ยืนป้องกัน Shelter ด้วยปืนไรเฟิลดัดแปลงและความรู้เรื่องเครื่องมือ
- **มีรา (Mira):** ผู้ส่งสัญญาณจากศูนย์อพยพ เสียงวิทยุที่ชี้เป้าภัยและค่อย ๆ เปิดข้อมูลของ Shelter 09; ไม่อ่านบทยาวระหว่างคลื่นหนัก
- **Hollows:** ฝูงสิ่งมีชีวิตกลายพันธุ์ ไม่มีบทพูด ใช้พฤติกรรมและรูปลักษณ์บอกชนิด/ภัย
- **Rift Warden:** Hollow ขนาดใหญ่ที่นำฝูงเข้าชนแนว Shelter

## โครงเรื่องหนึ่งภารกิจ (MVP)

1. **แนวป้องกัน:** รินเข้าประจำการหน้า Shelter 09; มีราขอให้ซื้อเวลาให้ทีมซ่อมเสา
2. **คลื่นแรก:** Drifter และ Skitter สอนการจัดตำแหน่งยิง การเก็บ Parts และการกันไม่ให้ศัตรูทะลุแนว
3. **ตั้งรับให้แข็งแรง:** ผู้เล่นเลือกระหว่างอัปเกรดปืนกับใช้ Emergency Blast หยุดศัตรูใกล้แนว
4. **เสบียงที่เหลือ:** หลังจบคลื่น Salvage ใช้เสริม Barricade ให้ Shelter ทนการบุกครั้งถัดไป
5. **Rift Warden:** บอสเข้าชนแนวที่เตือนล่วงหน้า; ผู้เล่นต้องเคลื่อนที่และใช้พลังที่สะสมมา
6. **สัญญาณตอบรับ:** หาก Shelter ยังอยู่ ทีมอพยพตอบกลับ แต่เส้นทางปลอดภัยยังต้องผ่านฝูง Hollows อีกหลายเขต

## การเล่าเรื่องในเกม

- ใช้ radio barks สั้น ๆ ก่อน/หลัง wave และเฉพาะเหตุการณ์สำคัญ
- ใช้ข้อความสรุปหลังภารกิจสำหรับข้อมูลที่ไม่ควรขัดจังหวะ action
- บันทึกเสียง/ข้อความ optional ให้ผู้เล่นเลือกอ่าน
- UI เตือนภัยด้วยไอคอน/ภาพ/เสียงที่ไม่บังบริเวณล่างของสนาม
- แยกข้อความด้วย localization key ตั้งแต่เริ่ม; ไม่ฝังประโยคสำคัญไว้ใน logic

## น้ำเสียงและธีม

- **น้ำเสียง:** มีความหวังแบบระมัดระวัง; คนธรรมดาช่วยกันด้วยการทำงานเล็ก ๆ ที่สำคัญ
- **ธีม:** การเตรียมอนาคตกับการช่วยชีวิตตรงหน้าเป็นคุณค่าที่แข่งขันกัน แต่ไม่มีทางเลือกใดถูกหรือผิดแบบตายตัว
- **หลีกเลี่ยง:** ความสิ้นหวังต่อเนื่อง, บทพูดยาวทับการเล่น, การลงโทษทางเนื้อเรื่องจากการแพ้

## ขอบเขตเนื้อเรื่อง

MVP เล่าเหตุการณ์หนึ่งภารกิจและหนึ่งบอสให้จบในตัว ส่วนหลายเขต/หลายตอนเป็นส่วนขยายหลังพิสูจน์ core loop แล้ว ไม่ต้องสร้างจักรวาลขนาดใหญ่หรือ cinematic ก่อน prototype
